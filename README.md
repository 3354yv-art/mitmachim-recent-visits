# מתמחים טופ – נושאים שביקרתי בהם

תוסף ל-Tampermonkey שמוסיף לפורום [מתמחים טופ](https://mitmachim.top) רשימה של הנושאים האחרונים שביקרת בהם.

## ✨ מה הוא עושה
- כפתור **"ביקרתי לאחרונה"** 🕘 בסרגל הצד (ובטלפון – כפתור צף)
- רשימה של עד 60 הנושאים האחרונים שביקרת בהם, עם הקטגוריה, מתי ביקרת וכמה פעמים
- לחיצה על נושא מחזירה **לפוסט שבו הפסקת לקרוא**
- חיפוש ברשימה, מחיקת נושא בודד וניקוי הכל
- קיצור מקלדת: **Alt+H**

הרשימה נשמרת רק בדפדפן שלך – שום דבר לא נשלח לשום מקום.

## 📥 התקנה
1. התקינו את [Tampermonkey](https://www.tampermonkey.net/)
2. לחצו כאן: **[התקנת התוסף](https://github.com/3354yv-art/mitmachim-recent-visits/raw/main/mitmachim-recent-visits.user.js)**
3. במסך שנפתח לחצו **Install**, ורעננו את מתמחים טופ
